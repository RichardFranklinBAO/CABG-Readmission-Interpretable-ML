# Data availability and reproducibility

The original CABG clinical dataset is not included in this code portfolio. Study participant data are not distributed here. The Git repository consists of source code, documentation and an independent synthetic-data example.

The archived notebooks use input filenames and directory conventions from the research environment. These references are not the underlying data. Researchers with appropriately authorized clinical data would need to configure their local paths and software environment to rerun the full scripts. Analyses in the archive include exploratory versions and have not all been verified against the publication's final reported metrics.

Notebook execution outputs were cleared before committing. The synthetic example in `examples/` uses artificial observations and its output should not be cited as CABG clinical performance.

Code-sharing permission with the supervising faculty was confirmed by the repository owner.
